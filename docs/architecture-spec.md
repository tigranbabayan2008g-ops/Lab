# Краткое описание архитектуры

Лабораторная работа выполнена в соответствии с архитектурным шаблоном **Layered Architecture (Многоуровневая архитектура)**:
* **Presentation Layer (Слой представления)** — контроллеры (`BookController`, `ReaderController`, `LoanController`). Отвечают за обработку запросов пользователя/библиотекаря и передачу данных в сервисы.
* **Application Layer (Слой приложения)** — сервисы (`BookService`, `ReaderService`, `LoanService`). Содержат логику сценариев библиотеки (выдача, возврат, поиск).
* **Business Layer (Бизнес-слой / Модель)** — сущности предметной области (`Book`, `Author`, `Reader`, `BookLoan`), их методы и интерфейсы репозиториев (`IBookRepository` и др.).
* **Data Access Layer (Слой доступа к данным / DAL)** — репозитории (`SqlBookRepository` и др.) и подключение к базе данных (`DatabaseConnection`). **Все SQL-запросы изолированы исключительно в этом слое**.
